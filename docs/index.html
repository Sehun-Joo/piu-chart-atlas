How these rankings work

Scoreability evidence: choose a target (default 990,000). We examine up to the top 100 leaderboard entries. Each entry at or above the target earns 1 point; entries in the 20,000 points below the target earn proportional credit; lower scores earn 0. The sum is an index from 0 to 100. Five PGs alone earn only 5 points. Eighty entries meeting the target earn at least 80. Unfilled slots provide no evidence; they are not assigned zero gameplay scores or treated as failed attempts.

The fixed depth avoids changing the denominator between short and capped leaderboards, and sits below PIU’s 300-entry limit. The 100-entry depth and 20,000-point margin are design choices, not fitted or validated parameters. This index rewards breadth of demonstrated scoring, so popular and older charts can still rank higher. Clear-only data omits failures and player skill; this cannot estimate clear rates, typical-player difficulty, or your success probability. Compare within a level and mode for more useful suggestions. Few records mean insufficient evidence, not proof that a chart is hard.

Every row is a separate Single or Double chart at level 20 or higher. Average uses exactly the highest X scores. Charts with fewer than X leaderboard entries are automatically excluded from average sorting. PG-count sorting includes them.

PIU publishes up to 300 leaderboard scores per chart. X is limited to 1–300. A Perfect Game is a score of 1,000,000. PG count covers leaderboard entries, not repeated plays. If all 300 entries are PGs, the count is shown as 300+ because the actual total is unknown. Counts otherwise describe the fetched leaderboard snapshot.
